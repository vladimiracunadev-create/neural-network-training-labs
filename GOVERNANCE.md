# Gobierno del proyecto

El mantenedor define el roadmap y aprueba cambios de arquitectura, datasets y políticas. Las decisiones deben quedar registradas en pull requests o ADRs dentro de `docs/adr/`.

## Criterios de aceptación

- utilidad educativa o experimental clara;
- fuente de datos verificable;
- cumplimiento de licencia y privacidad;
- prueba de ausencia de fuga;
- reproducibilidad razonable;
- costo de mantenimiento proporcional;
- documentación de riesgos.

## Cambios incompatibles

Se documentan en `CHANGELOG.md`, incrementan la versión mayor y ofrecen una ruta de migración cuando sea posible.
