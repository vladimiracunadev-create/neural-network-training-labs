# Soporte

Antes de abrir un issue:

1. Ejecute `neural-labs doctor`.
2. Ejecute `neural-labs validate`.
3. Repita con `--quick --device cpu`.
4. Adjunte el error completo, sistema operativo, versión de Python y `environment.json` sin secretos.

Los problemas de acceso a Kaggle, aceptación de licencias o cuotas del proveedor deben resolverse en la cuenta correspondiente; el repositorio no elude esas restricciones.
